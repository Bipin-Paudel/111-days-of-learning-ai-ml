# Day 27: One-Hot Encoding

**🚀 Day 27 of the 111 Days of Learning challenge is complete!**

Today I learned how to convert categorical features into machine-friendly numeric form using one-hot encoding:

- 🧩 **Pandas `get_dummies`:** How to create dummy columns quickly from categorical features.
- 🔁 **K-1 Encoding:** How `drop_first=True` removes one redundant column.
- 🛠️ **Scikit-Learn `OneHotEncoder`:** How to encode training and test sets consistently.
- 📦 **Top Categories Handling:** How to group rare values before encoding for cleaner feature spaces.

This made categorical preprocessing feel much more practical for ML workflows. 💡
