# Day 28: ColumnTransformer

**🚀 Day 28 of the 111 Days of Learning challenge is complete!**

Today I learned how to combine multiple preprocessing steps cleanly with `ColumnTransformer`:

- 🧼 **SimpleImputer:** How to fill missing values in numeric columns like `fever`.
- 🔁 **Ordinal Encoding:** How to encode ordered categories like `cough`.
- 🧩 **One-Hot Encoding:** How to encode categorical columns like `gender` and `city`.
- ⚙️ **ColumnTransformer:** How to apply different transformers to different columns in one pipeline.
- 🧠 **Passthrough Columns:** How to keep unchanged features while transforming the rest.

This made preprocessing feel much more organized and scalable. 💡
