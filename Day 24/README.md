# Day 24: Feature Scaling

**🚀 Day 24 of the 111 Days of Learning challenge is complete!**

Today I learned how feature scaling helps machine learning models work better on numeric data:

- 🔀 **Train-Test Split:** How to separate data before learning scaling parameters.
- 📏 **StandardScaler:** How to standardize features using the training set only.
- 📉 **Distribution Check:** How scaling changes the shape and spread of variables like `Age` and `EstimatedSalary`.
- ⚙️ **Model Comparison:** How scaling affects models such as Logistic Regression and Decision Trees.

This made preprocessing feel like a critical part of the ML pipeline. 💡
