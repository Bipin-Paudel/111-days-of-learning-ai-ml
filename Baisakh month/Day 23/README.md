# Day 23: Feature Engineering

**🚀 Day 23 of the 111 Days of Learning challenge is complete!**

Today I revisited feature engineering and explored how raw data can be prepared for machine learning models:

- 🧹 **Missing Value Imputation:** How to fill missing values using domain-aware choices like the average age.
- 🧱 **Feature Transformation:** How to change features into a more useful form for modeling.
- 🧩 **Feature Construction:** How to build new features from existing ones.
- 🎯 **Feature Selection:** How to choose the most useful features.
- 📉 **Feature Extraction:** How techniques like PCA can reduce dimensionality while keeping important structure.

This made feature engineering feel like the real bridge between raw data and ML-ready input. 💡
