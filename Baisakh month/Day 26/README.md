# Day 26: Ordinal Encoding and Label Encoding

- 🧠 **Customer Data Prep:** How preprocessing helps turn a raw customer dataset into ML-ready input.
- ⚙️ **Scikit-Learn Workflow:** How to fit encoders on training data and apply them consistently.

This made categorical preprocessing feel simple and practical. 💡
