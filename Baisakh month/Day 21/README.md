# Day 21: Titanic Data Exploration and Univariate Analysis

**🚀 Day 21 of the 111 Days of Learning challenge is complete!**

Today I explored the Titanic `train.csv` dataset and practiced univariate analysis with Pandas and Seaborn:

- 📦 **Data Loading:** How to read the dataset and inspect its size, types, missing values, and summary statistics.
- 🧭 **Categorical Analysis:** How to use count plots and pie charts to understand columns like `Embarked` and `Sex`.
- 📊 **Numerical Analysis:** How to explore distributions with histograms, distplots, and boxplots.
- 🔍 **Quick EDA Habits:** How to check duplicates and correlation before moving deeper into analysis.

This made exploratory data analysis feel more structured and practical. 💡
