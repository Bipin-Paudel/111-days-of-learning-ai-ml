# Day 22: Pandas Profiling and Bivariate Analysis

**🚀 Day 22 of the 111 Days of Learning challenge is complete!**

Today I explored the Titanic dataset from two angles: automated profiling and bivariate analysis.

- 📋 **Pandas Profiling:** How to generate a full exploratory report quickly with `ydata-profiling`.
- 🔍 **Data Inspection:** How to use profiling to spot missing values, distributions, and correlations.
- 📊 **Bivariate Analysis:** How to compare two variables with scatter plots, bar plots, box plots, distplots, and heatmaps.
- 🧠 **Pattern Discovery:** How relationships between features can reveal structure that one-variable analysis misses.

This made exploratory data analysis feel faster and more complete. 💡
