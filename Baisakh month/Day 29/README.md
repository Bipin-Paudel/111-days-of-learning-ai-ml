# Day 29: Pipelines for Titanic Preprocessing

**🚀 Day 29 of the 111 Days of Learning challenge is complete!**

Today I learned how to simplify a Titanic ML workflow by using pipelines:

- 🧹 **Manual Preprocessing:** How to handle imputation, one-hot encoding, and feature assembly step by step.
- 🔁 **Pipeline Workflow:** How `ColumnTransformer` and `Pipeline` keep preprocessing and modeling together.
- 🎯 **Model Training:** How a Decision Tree can be trained on a transformed feature set.
- 📦 **Prediction Flow:** How pipelines make inference easier by reducing manual transformation code.

This made end-to-end ML workflows feel much cleaner and easier to maintain. 💡
