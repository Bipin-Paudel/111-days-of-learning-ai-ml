Today's notebook explores **complete case analysis** with Pandas on the `data_science_job.csv` dataset.

## What I learned

- Checked missing values across columns using `isnull().mean() * 100`
- Selected columns with a small amount of missing data
- Created a cleaned dataset with `dropna()`
- Compared distributions before and after cleaning to see whether dropping rows changes the data shape

## Key takeaway

When missing values are limited, complete case analysis can be a simple way to clean data, but it is important to compare the original and cleaned datasets first so we do not introduce bias.
